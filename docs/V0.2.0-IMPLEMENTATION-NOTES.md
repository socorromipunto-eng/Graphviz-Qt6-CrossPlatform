# v0.2.0 build automation candidate

Status: **UNTESTED CANDIDATE — NOT A RELEASE**. Historical Windows x64 runtime evidence is preserved in main and not reproduced by these scripts.

## What's new
- Parameterized Windows x64 configure/build runner with read-only preflight by default and explicit `-ExecuteBuild` mutation boundary.
- Parameterized macOS configure/build runner with read-only preflight by default and explicit `--execute` mutation boundary.
- Existing runtime smoke test remains in main unchanged.

## Windows example (PowerShell 5.1)
```
.\scripts\Invoke-GVQ6WindowsBuild.ps1 -SourceDir 'C:\path\graphviz-source' -BuildDir 'C:\path\new-build' -QtPrefix 'C:\Qt\6.12.0\msvc2022_64' -CMakeExe 'C:\path\cmake.exe' -ExpectedSourceCommit '<40-char source commit>'
```
First run **without** `-ExecuteBuild`. A separately authorized run adds that flag. Dependencies (including Flex/Bison) must already be available in the selected toolchain environment. No automatic install is performed.

## macOS example
```
sh scripts/Invoke-GVQ6MacOSBuild.sh /path/graphviz-source /path/new-build /path/to/Qt/6.x/macos
```
The same invocation may add `--execute` only with explicit authorization. This script is not tested on Intel or Apple Silicon macOS; dependencies, targets, and GUI runtime need verification.

## Known constraints
- No portable transitive dependency resolver, package manager integration, binary packaging, macOS universal binary, CI, or notarization.
- `WITH_GVEDIT=ON` requests the feature; runner does not assert that target generation succeeded until the build invocation.
- Builds may fail when prerequisites are unavailable. Failed builds can leave partial output **only inside the new build directory**; no rollback is automated.
- No Graphviz or Qt third-party source/binary is bundled. Licensing review is required before redistributing binaries.
- In future, derive the plugin config filename from generated `config.h` (historical version used `config8`), never hardcode `config6`.
